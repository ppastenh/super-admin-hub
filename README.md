# Super Admin Hub

Al igual que el panel de mi proyecto Crossfit para administrador, necesito crear uno para el super admin quien maneja copletamente todo 
controla la app completa, aprueba boxes nuevos
resumen general arriba (boxes activos, pendientes, total de alumnos en toda la plataforma), boxes por aprobar, y el listado completo de boxes activos con su estado.
Ese panel puede tener un botón para "entrar como alumno/admin"
Otorgar permiso — buscas al usuario en tu panel y le das el rol de admin de box con un botón.
